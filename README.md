# 三命通会 · 八字分析技能包

> 基于明代命理巨著《三命通会》蒸馏而成的 AI 八字分析技能包（10 个技能）。

把《三命通会》的格局、神煞、纳音、日时断法、六亲、性情、疾病、寿夭等断法规则，从古籍中结构化提取为可直接被 AI 调用的 `SKILL.md` 技能。结论来自古籍规则匹配，用于命理研究与内容创作参考。

## 安装

1. 打开你的 AI 助手的「技能 / 插件 / Skills」入口。
2. 点「导入 / Import」，选中 `技能包/` 里的**某一个技能文件夹**（例如 `sanming-zhengguan-ge`）。
3. 导入后启用即可。每个技能是一个独立文件夹，里面只有一个 `SKILL.md`，一次导入一个文件夹。

> 全部 10 个技能共用同一套八字模型，直接全开会互相抢触发。建议按要问的方向只开启 1–3 个。详细用法见 `怎么用.md`。

## 使用示例

给助手一个八字排盘（年柱 月柱 日柱 时柱），然后问对应领域的问题：

```
你：帮我看这个八字：庚戌 乙酉 乙酉 乙酉，是不是正官格？官运怎么样？
助手：（触发 sanming-zhengguan-ge）先取月令——酉月辛金当令，乙木日主……此造实为七杀格从化之局……
```

## 说明与免责声明

- **不是算命**：本技能包是《三命通会》断法规则的结构化检索系统，结论来自古籍规则匹配，不构成任何人生决策建议。
- **低置信技能**：`sanming-waige`（外格极罕见）、`sanming-naying`（纳音现代使用率低）、`sanming-rishi`（只看日时忽略月令）、`sanming-nvming`（女命章带封建色彩）已标注适用边界，结果仅供参考。
- 每个技能 `SKILL.md` 末尾的「待裁决项」是书中自相矛盾、蒸馏时无法定夺的规则，AI 会两条并列呈现，最终需结合上下文把握。
- 女命、贫贱、寿夭等章节含明代社会观念，请勿用于歧视性判断。
