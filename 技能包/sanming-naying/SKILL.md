# 三命通会·纳音断法（sanming-naying）

本技能对应《三命通会》卷一、卷二「论纳音」体系。作者万民英属综合派，主张「本之以五行为经，参之以纳音为纬」——纳音并非虚文，确有断事作用，与纯子平派不同。核心抓手为「禄命身三才」（干为禄、支为命、纳音为身），并以纳音取象（海中金、剑锋金、炉中火……）配合正五行，按「成器与否」「旺相死休囚」定吉凶。

## 什么时候用它

- 用户询问某八字「纳音是什么、纳音喜忌如何、纳音主什么事」。
- 已经排好四柱、走完正五行/十神主线，需要再用纳音维度加强或修正判断（如定贵贱寿夭、取象、看器物成败）。
- 命局中出现明显的纳音格局（如砂中土得二金资养、海中金归大海、火土入堂、龙归大海等）。
- 需要判断「神煞/格局」是否要兼纳音造化合参（书中强调神煞不可孤断）。

## 涉及的模型节点

- `L4本书技法 > 纳音`（禄命身三才 / 成器判定 / 十二宫取象 / 六十甲子性质 / 旺相死休囚）
- `L8断事维度 > 纳音断事`（贵贱、寿夭、荣枯、功名、性情取象等）
- 合参节点：`L1四柱`、`L2十神`、`L3五行`（正五行底层）、`L5用神`、`L6神煞`

## 核心判断

拿到八字，先认「纳音这层皮」：日主或年命的纳音五行是什么物象（金是海中/剑锋/砂中？火是炉中/霹雳/天上火？），再按三步定其「活不活、成不成、吉不吉」：

1. **禄命身三才**——干禄、支命、纳音身三者旺相有气则命主安乐长寿；死绝休囚无气则困窘。
2. **成器与否**——未成器之金土须火陶铸方贵，已成器者反忌火克；同类互见要比体量大小。
3. **旺相死休囚**——纳音落支位有十二宫旺衰，值旺相则象成，值死休囚则象败（个别已成之象反例见规则集）。
4. **与正五行合参**——纳音断语不能单走，须与正五行生克、十神、神煞合看；真五行克纳音为真官。

## 断法步骤

**步骤1 · 定本命纳音** `[L4本书技法 > 纳音 > 六十甲子性质]`
先排四柱纳音，认年命与日主纳音为何物（如甲子乙丑海中金、丙寅丁卯炉中火）。确定全命局以哪一纳音为主象（年命为体、日主为用，二者冲突时以日主纳音为近身之象）。

**步骤2 · 禄命身三才旺相** `[L4本书技法 > 纳音 > 禄命身三才]`
看干（禄）、支（命）、纳音（身）三者是否得旺相、有无气。三才俱旺相有气→快乐长寿；值死绝休囚无气→尘埃困窘。禄命身各有财库，可分别看其库位是否被破。

**步骤3 · 纳音成器与否** `[L4本书技法 > 纳音 > 成器判定]`
判断主象纳音是「已成器」还是「未成器」。未成器者（金土多类）喜火陶铸、喜生扶，无火制则埋没贱夭；已成器者喜清润生扶、忌火克坏。同类互见（如两木、两金）要比盛衰体量，定「舍大就小 / 弃小论大」。

**步骤4 · 纳音取象** `[L4本书技法 > 纳音 > 十二宫取象]` + `[L4本书技法 > 纳音 > 六十甲子性质]`
按纳音物象取象（珠藏渊海、朱雀腾空、龙归大海、火土入堂等），并看纳音落在何支位（十二宫），定人生对应阶段之旺衰。取象须先判旺相死休囚——旺相则象成，死休囚则象败。

**步骤5 · 与正五行合参** `[L3五行]` + `[L2十神]` + `[L5用神]` + `[L6神煞]`
纳音断语不可孤断：与正五行生克、十神格局、用神得失、神煞（如亡神须兼造化）合参。真五行克纳音为真官；鬼多而主本有气则鬼化为官；身旺鬼绝则长年，鬼旺身衰则夭寿。

**步骤6 · 断事** `[L8断事维度 > 纳音断事]`
综合上述五步，按「贵贱 / 寿夭 / 荣枯 / 功名 / 性情取象」等维度落结论。注意同纳音相反断语必须注明条件差异（见规则集冲突裁决列）。

## 参考命例

> 选自本书纳音命例，演示断法步骤落地。

**例1 · 明太祖（戊辰 / 壬戌 / 丁丑 / 丁未）—— 大林木「大林龙」见天河、四库全**
- 年柱戊辰纳音大林木，取象「大林龙」；时柱丁未纳音天河水→龙飞在天成立。
- 地支辰戌丑未四库全备→「四海俱备，雨泽及于天下」。
- 断：龙得云雨且四库全，九五之象。〔步骤4取象 + 步骤6断事〕

**例2 · 王阳明（壬辰 / 辛亥 / 癸亥 / 癸亥）—— 长流龙归大海**
- 年柱壬辰纳音长流水，为「长流龙」；月日时三亥，龙得亥→龙归大海/龙跃天门。
- 癸亥纳音大海水，四柱俱带水→五湖既多且深，龙所益喜；月干辛金生水。
- 断：出入动摇山岳，封伯之贵。〔步骤4取象 + 步骤5合参水旺成势〕

**例3 · 丙辰年造（丙辰 / 乙未 / 癸酉 / 戊午）—— 砂中土得二金资养、太阳照**
- 年命丙辰砂中土为主象；月乙未沙中金、日癸酉剑锋金→「二金资养」；时戊午天上火照→朱雀腾空格，贵。
- 全柱无水纳音，失「水相涵」上吉，降一等；戊午太燥，贵而寿数受限。
- 断：贵，寿因火燥而减。〔步骤3成器 + 步骤4取象 + 步骤6寿夭〕

**例4 · 丙寅年造（丙寅 / 丁酉 / 己酉 / 丙寅）—— 炉中火无气不失大贵**
- 日主己酉大驿土，年时双丙寅炉中火本可炽；但月日支皆酉，火死于酉→纳音火「为无气」。
- 火无气不燥，大驿土不受「凡火加燥」之害，反得火生土之正用；带亡神，兼造化（火无气）而凶解。
- 断：不失大贵。〔步骤4旺相死休囚 + 步骤5与神煞合参〕

**例5 · 丙寅年造（丙寅 / 甲午 / 己巳 / 丙寅）—— 炉中火炎无制漂泛**
- 年时双丙寅炉中火，月午日巳与寅成火局，势极盛；日主己巳大林木为薪助火炎。
- 全柱无水纳音，火无制约（用神失位）。
- 断：火炎无制，主漂泛不安（甚则凶暴疾夭）。与例4同是丙寅炉中火，旺相/无气结局相反。〔步骤4旺相死休囚 + 步骤5合参〕

**例6 · 丁巳年造（丁巳 / 癸卯 / 己未 / 壬申）—— 砂中土得天上火（缓）照**
- 年丁巳砂中土为主象；月癸卯金箔金、时壬申剑锋金→二金资养；日己未天上火照→贵。
- 与例3同「二金+天上火、无水」结构，但己未为太阴之火气缓，寿优于戊午照者。
- 断：贵且寿较优。〔步骤3成器 + 步骤6寿夭（旺相火性缓急）〕

## 判断标准

- **成器/未成器先判定**：未成器喜火炼、已成器忌火克，喜忌相反，不可混用。
- **旺相死休囚优先于取象**：同一纳音物象，值旺相则吉象成，值死休囚则吉象败（个别已成之象如桑柘木反格除外，见 R15）。
- **同类互见比体量**：两木、两金相见先定盛衰，定「舍大就小 / 弃小论大」。
- **合参不可省**：纳音断语须与正五行、十神、用神、神煞合看；神煞尤须兼造化（如亡神）。
- **冲突裁决优先**：同纳音出现相反断语时，按规则集「冲突裁决」列注明条件差异；C-4（大海水壬戌）为待裁决项，暂以清浊分判为主。

## 什么时候不该用它

纳音现代命理实践使用率低，多作为辅助维度，不可替代正五行与十神格局主线：当用户只问十神格局、用神喜忌、大运流年等纯子平问题，或命局毫无纳音取象/成器/禄命身可论之处时，不应调用本技能；纳音断语亦不可单走定生死，须回正五行合参。

## 共享断法步骤 · 用神与行运总则

取用先观月令与日主强弱，行运喜忌随格局而定。月令为命局提纲，四吉（财官印食）为取用大纲；身弱喜印比而忌财官杀，身强喜财官而忌印比；岁运互动须审冲克、并临、伏吟与阳刃冲岁，终以原局旺衰合参定吉凶。

1. **定用神** — [L5用神体系>取用总则] 先观月令所藏与日主强弱，定财官印食四吉为用；辨扶抑（太过抑之、不及扶之）与从化（欲从从、欲化化），忌用神损伤。

3. **查岁运互动** — [L7大运流年>岁运关系] 看岁运冲克方向（岁冲运则崩、运冲岁则晦）、岁运并临（惟带羊刃七杀者凶）、伏吟反吟、阳刃冲合岁君，定凶神是否被触发。

## 赋文心法附录

以下为《三命通会》卷十至卷十二赋文口诀（看命口诀、巫咸撮要、玉井奥诀、气象篇、六神篇、憎爱赋、明通赋、喜忌篇、元理赋、金声玉振赋、继善篇、四言独步、真宝赋等）的浓缩心法。赋文是全书断法以口诀形式的总结：以子平六格为纲，气象篇论气势、六神篇论十神、喜忌篇论格局喜忌。分析时先走本技能的正规断法步骤，再以本附录参证——口诀为心法，不作独立断语；凡与正文规则冲突者，以正文触发条件为准。另：「十干十二年生大贵人例」一类以年月日时机械定贵之诀，作者万民英自按「天下八字同者甚多未必皆贵……年月日时多不足凭」，本附录仅存录旧说，不得作断贵依据。

### 气象与六神（气势/十神心法）

- 富莫富于纯粹，贫莫贫于战争；贵莫贵于秀实，贱莫贱于反伤——先定全局清浊战和，再论十神得失。
- 形全者宜损其有余，形缺者宜补其不足；固用不如固本，花繁岂若根深——气势偏于一方者，抑高举下方合中和。
- 阳刚不中，刚而能柔乃吉：五阳干生阴月、干支夹合阴柔之物、运行阴柔之乡者，虽出寒贱终必荣华；亢阳无制而再行东南，孤贫凶暴。
- 过寒过燥皆失气象：四柱纯阴生十月而五行绝根者，纵遇和暖之乡终难发达；四柱纯火生夏至前，岁运乍遇水激反致其害。
- 金水过于清冷（庚辛生十月柱中纯水而运行西北），主独食孤眠、生涯寂寞——清则贵，冷则孤。
- 取用贵在自然：柱中现成之物为妙。用财而局中不见，转求食伤生之、再求比肩助之、又求外冲遥合者，过于用力，成就必艰。
- 五行绝处不可便指为凶：绝地之中藏禄马财官者（如土日绝申而申藏壬印庚戊财官），反能扶身进福。
- 吉神相我，功求相吉之神；凶物伤身，解用伤凶之物——救应之神须先自强，弱救不能救人。
- 一将当关，群邪自服：煞重得一位食神透干制之、或得印化煞，煞自服；众凶克主而无当关之神者，独力难胜，主夭疾。
- 日干旺而有财官食伤可依者，灾咎少；旺甚无依、无制无泄者，不为僧即为道。（H-6 双条：分界在「旺」与「旺极无依」）
- 身旺鬼衰而无财生印化、制煞太过者，定作凶徒；煞本旺而得月令之制、身煞两停者，煞反为权印——旺中有制方全福。（H-2 双条：分界在煞之本旺与制化是否得中）
- 火土贵在分明有序：火居上生土、成局而无水破者为「照象」，主贵显；火见土则暗、土宿火则晦，二气互相掩蔽夹杂者，主愚浊碌碌。（H-5 双条：判别关键在清纯有序抑或夹杂掩晦）

### 格局喜忌口诀（喜忌篇/明通赋/继善篇）

- 四柱排定，三才次分；专以日上天元配合八字，先观月令而论格，次论财官去留舒配——独则易取，乱则难明。
- 官星喜身旺、印绶、食禄而以财为引；柱中官星太旺则为天元羸弱，反须印比扶身。
- 官煞交差却以合煞为贵；去留舒配论格要精——留官去煞或留煞去官，皆取得令有力者为主，混而无制则贱。
- 时逢七煞未必为凶：月令有制、日干强者，煞反化为权印，此为通例。
- 年干岁德之煞（尊位独煞）其煞最重、终身不可除，最喜财星印绶羊刃相扶而不可制伏——与月令、时上之煞宜制者分位而论。（H-1 特例）
- 食神制杀为福，一位有制者贵；食神孑立逢枭而柱无偏财御敌者，命当夭折。
- 伤官务要伤尽，见官祸患百端——然五行有别：火土伤官宜伤尽，金水伤官要见官，木火见官官要旺，水木伤官财官两见始为欢（五行细则优先于通则）。
- 伤官身旺者用财，身弱者用印：无财泄、无印制则克夫损子；伤官生财或伤官佩印而不被刑冲者，不凶反贵。（H-9 双条）
- 印绶生月者，岁时忌见财星，运入财乡宜退身避位——此限于身弱赖印为用者。
- 印旺身强，或印司令而须财生煞通关者，财印相资无刑冲反登三公——印之轻重定财之吉凶。（H-3 双条：印为用则忌财，印重身强则喜财）
- 羊刃七煞两凶相济：岁时带印财、无刑冲填实者，威权大贵；逢刑冲、岁运并临而无制化者，灾殃立至乃至法场。（H-4 双条）
- 劫财阳刃切忌时逢，岁运并临灾殃立至——作者自辨：此断惟命带羊刃、七煞者应之，非无条件凶。
- 财官印绶全备藏蓄于四季（杂气）；官库财库冲开则荣，塞闭则贫；月令虽逢建禄切忌会煞，建禄不富、背禄不贫，一见财官方能发福。
- 日禄归时没官星，号青云得路；拱禄拱贵填实则凶；时上偏财别宫忌见，最忌比肩争夺。
  - **待裁决**：明通赋「丙日癸巳时日禄归时又遇官反贵」与本条「归禄忌官」相抵。通例仍以忌官星、忌财透为主，丙日癸巳（巳为丙禄、癸官同宫得贵）与庚日甲申时归禄带财两例作特例存参，不得与通则并列。
- 有病方为贵，无伤不是奇；格中如去病，财禄喜相随——格局成败先寻病神，能去病者方论贵。
- 弃命从财、从煞须四柱无一点比劫印绶根气；日主尚有微根而不能从者，是富屋贫人、因财构祸。
  - **待裁决**：元理赋「弃干从煞论刚柔，金水土可从、木火不可从」与四言独步「丙火申提无根则从煞」正相反。暂两存，以「是否彻底脱根」为分界：木火多有余气，非局全煞旺而彻底无根者不轻言从。

### 行运与取用口诀（看命口诀/巫咸撮要/玉井奥诀）

- 看命先看月令深浅、五行当令之气，次论官煞财印之向背与提纲之轻重——月令为命之根，取格以月令为正。
- 推造化以日为主，先识本象与化象；地支四位比天干更切，专看冲、拱、刑、合四件，审何者力重，即为用神基业。
- 用神即尊长、权神、号令：最忌损犯、分窃、太过与不及；用神不可损伤，日主最宜健旺；太过而岁运再生则倾覆。
- 年干统摄，须引于有气贵地；时座如秤锤，分毫加减尽在时上——平生祸福赖于日时，一岁吉凶凭于气运。
- 看子平专论财官，以月上财官为紧，而发觉在日时、消详在强弱：入格者非富即贵，不入格者非贫即夭。
- 八字全无财官贵气，而五行相生自立成象者（金水象、金土象、水木象、木火象之类），亦能奋发富贵——不可专执贵气取断。
- 贵气多重而身无气者不能任，须从化、从象方吉——身能任其气，是一切成贵之前提。
- 强者宜泄不宜克：强金得水方挫其锋，强木得火方化其顽。生我太过反受其害（土多金埋、水多木漂），我生太过反自损（水多金沉、火多木焚），克而不胜反受其伤（木坚金缺、土重木折）。
- 身财官三配定运：日主旺而财官弱者，运入财官利名驰；财官旺而日主弱者，运行身旺最为奇；财多身弱畏入财乡，煞重身轻制乡为福。
- 印格逢财运，以印之轻重定吉凶：印重煞轻者行财旺运克太过之印、生不及之煞，是「贪财坏印擢高科」；印本轻而为唯一用神者，逢财破印则罢职、甚而恶中亡。
- 得地失时如田畴得雨，得时失地如輗损途泥；火到南方而荣，水临北地而盛——运须与时、地相参，不可单看五行名目。
- 运以支重为基，岁以干重乘气；太岁为众煞之主，岁冲运则崩、运冲岁则晦（旧说「岁伤运反吉」存参不用）。岁君最严最切：非岁不能激扬吉凶，运元未萌，非岁则不发。
